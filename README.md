# Latihan CRUD

Kumpulan project latihan CRUD (Create, Read, Update, Delete) menggunakan berbagai teknologi dan bahasa pemrograman.

## 📁 Daftar Project

| Project | Tech Stack | Deskripsi |
|---------|-----------|-----------|
| **CRUD-C#** | C# / Windows Forms / .NET | Aplikasi CRUD desktop menggunakan Windows Forms |
| **CRUD-JS-Java** | Node.js (Express) + Android (Java/Kotlin) | API backend Express.js dengan client Android |
| **CRUD-Laravel** | PHP / Laravel | Aplikasi web CRUD menggunakan framework Laravel |
| **CRUD-PHP** | PHP Native | Aplikasi web CRUD menggunakan PHP murni |
| **CRUD-React-Go** | React.js + Go (Golang) | Frontend React dengan backend API Go |

## 🚀 Cara Penggunaan

Silakan masuk ke masing-masing folder project untuk melihat instruksi lebih lanjut.

## 📝 Database

File `db_login_android.sql` tersedia di root untuk setup database Android login.

## 📋 Prasyarat

- **CRUD-C#**: Visual Studio, .NET Framework
- **CRUD-JS-Java**: Node.js, Android Studio, JDK
- **CRUD-Laravel**: PHP 8.x, Composer, MySQL
- **CRUD-PHP**: PHP, MySQL, Web Server (Apache/Nginx)
- **CRUD-React-Go**: Node.js, Go 1.18+
